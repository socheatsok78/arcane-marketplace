How the registry works

Each template lives in templates/<id>/ in the GitHub repository. On every merge to main, CI generates registry.json, which is currently at v1.2.7 with 13 templates.

Use it in Arcane

  1. Open Settings → Templates in Arcane.
  2. Add https://arcane-marketplace.socheat.dev/registry.json as a registry.
  3. Pick a template, fill in its environment values, and deploy.

Template files

compose.yaml
The Compose project. Images track :latest, except databases pinned to a major version.
.env.example
Every variable the compose file uses without a default. Secrets are placeholders.
template.json
Name, description, author, icon_url and tags. version is optional.
README.md
Deployment notes: first-run steps, paths and links to upstream docs.

Versioning

Every template carries a content_hash computed from template.json, compose.yaml, .env.example and README.md, so Arcane can see when a template changed.

minor

New template

Adding a template directory bumps the registry's minor version.

patch

Changed or removed template

Any change to a template's files, or removing a template, bumps the registry's patch version.

patch

Template versions

If template.json leaves out version, the template's version gets a patch bump whenever its content_hash changes. A version written in template.json always wins.

Contributing

vp install
vp run new my-app             # scaffold templates/my-app
vp run lint:templates my-app  # check it, add --fix for automatic fixes
